G33k's Importer — hosted setup

Tiny bookmark, code loaded from this page's website. Works in Yandex, Firefox, Samsung Internet — and often Chrome too.

Step 1 — Copy the short bookmark code

If copy fails: long-press inside the box → Select all → Copy.

Step 2 — Create the bookmark

  1. Open any page in Yandex / Firefox / Samsung Internet, tap the menu (⋮), then Add to bookmarks.
  2. Open the bookmarks manager and find the bookmark.
  3. Long-press it → Edit.
  4. Long-press the address / URI field → Select all → Paste (replaces the old address with the code).
  5. Rename to G33k's Importer and Save.

Step 3 — Test it

  1. Open example.com (a neutral page with no security settings).
  2. Open bookmarks and tap G33k's Importer.
  3. A small dark panel should appear at the bottom right.
If it appears here, it will work on FictionLab too.

Step 4 — Use it on FictionLab

  1. Open https://fictionlab.ai and sign in.
  2. Go to New Scenario or open a scenario and tap Edit / Customise (address must show /create-scenario or /edit-scenario/...).
  3. Open bookmarks → tap G33k's Importer → the panel appears.
  4. Tap Choose file and select fictionlab_export.json.
  5. Tap Start and wait. When it finishes, tap Save / Publish on the FictionLab page yourself.
Notes: the JSON file must be on the phone (e.g. in Downloads). The bookmark needs internet access the first time (it loads the code from this website). If a page shows an alert about loading the code, that website blocks it — use the long-code version instead.

Troubleshooting

  1. Panel doesn't appear on example.com — the bookmark wasn't saved or the browser blocked it. Edit the bookmark: the address must start with javascript: and end with })();.
  2. Alert says it could not load the code — this page's website is offline or the link is wrong; tell the person who set this up.
  3. Alert on fictionlab.ai but not on example.com — FictionLab blocks loading external code; use the long-code version instead.
  4. "That file is not valid JSON" — the file must be the fictionlab_export.json from G33k's Exporter.
  5. "Open FictionLab's scenario editor" — you're not on a New Scenario / Edit page yet.
